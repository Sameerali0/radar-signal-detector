# Radar Signal Detector

This project is a Radar Signal Detector that shows a radar animation scanning the area and detecting random signals as glowing dots on the screen. Each detected signal displays a random user’s name, country, and picture using the RandomUser API. The project also includes Pause and Resume buttons to control the radar’s movement. It’s a fun and interactive project that combines canvas animation with real-time data fetching, designed to look visually appealing with a glowing radar effect.

## Technologies Used

- CSS
